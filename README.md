# ML-Tutorial
This Machine Learning (ML) tutorial was used in summer 2026 to teach high school students the basics of exoplanet detection and Machine Learning at TIFR, Mumbai.

The students' and teachers' versions are for speciifc purposes. One can scan the project objectives and flow from the mindmaps and hand-outs.

The data is collected from the NASA's Kepler database. The whole project was made using Claude by Anthropic.
